Установка расширения

Способ установки зависит от браузера. Ниже — проверенные на практике варианты, от «один клик с сайта» до ручной установки.

Вариант 1. Chrome — установка в один клик (работает)

Chrome позволяет ставить расширение прямо с этого сайта, если один раз разрешить установку политикой. Обновления потом приходят автоматически.

  1. Скачайте файл политики: install-policy.reg.
  2. Нажмите по нему правой кнопкой → Слияние, согласитесь на запрос UAC и добавление данных в реестр.
  3. Полностью закройте Chrome (все окна; проверьте, что в трее не осталось процессов) и запустите заново.
  4. Проверьте: chrome://policy → включите «Показывать не заданные политики» → найдите ExtensionInstallSources со статусом ОК.
  5. Нажмите «Установить в один клик» выше и подтвердите добавление расширения.

Ключевая деталь: списковые политики в реестре должны храниться как подраздел с нумерованными значениями (ExtensionInstallSources → 1, 2, … типа REG_SZ). Формат REG_MULTI_SZ браузеры не читают, и политика при этом выглядит как «не задана».

Вариант 2. Яндекс Браузер — установка перетаскиванием архива

Яндекс Браузер не разрешает ставить сторонние расширения с сайтов (политикой это не снимается), но позволяет установить расширение, перетащив архив в специальную страницу настроек Браузера.

  1. Скачайте ZIP-архив — распаковывать его не нужно.
  2. Откройте в Браузере страницу browser://tune.
  3. Откройте папку со скачанным архивом и перетащите архив в окно Браузера.
  4. Подтвердите установку — расширение появится в разделе «Из других источников».

После установки Яндекс Браузер может показать предупреждение о расширении из другого источника — это ожидаемо для расширений, установленных вручную. Расширению нужен только доступ к хранению настроек (storage), чтобы запомнить заданный вами курс. Установка выполняется один раз на компьютере и дальше не повторяется.

Вариант 3. Автоустановка на парк ПК

Политика ExtensionInstallForcelist устанавливает расширение автоматически, вообще без действий пользователя. Но она работает только на корпоративных (управляемых) компьютерах: входящих в домен, присоединённых к Azure AD или управляемых через консоль. На обычном домашнем ПК Яндекс Браузер отклоняет такую установку с сообщением «этот компьютер не является корпоративным».

install-policy-forcelist.reg Политики Sources + Allowlist + Forcelist (для управляемых ПК)

Настройка курса

  1. Нажмите на иконку расширения в панели браузера — появится поле «Курс (₽ за 1 ¥)».
  2. Введите значение, например 12.50 (значит 1 ¥ = 12,50 ₽), и нажмите Сохранить.
  3. Откройте platform.deepseek.com — цены в рублях появятся рядом с ценами в юанях.

Технические данные

  • ID расширения: cdoacknmgmgemgkhjemnlcmebofaldnb
  • Файл расширения: yen-to-rub.crx (CRX3, подписан RSA-2048)
  • Манифест обновлений: update.xml
  • Политика разрешения источников: install-policy.reg
  • Политики для управляемых ПК: install-policy-forcelist.reg
  • Скрипты: APPLY-POLICY.bat и CLEAN-POLICY.bat
  • Ветки реестра: HKCU, HKLM (64-бит) и HKLM WOW6432Node (32-бит) для Яндекс Браузера, Chrome и Chromium

Если что-то не работает

  • Политика «не задана» — почти всегда неверный формат: нужен подраздел ExtensionInstallSources с нумерованными значениями REG_SZ, а не REG_MULTI_SZ. Либо браузер не был перезапущен полностью.
  • «Сайт не доверенный» в Яндекс Браузере — это встроенное ограничение на установку сторонних расширений с сайтов, политикой оно не снимается. Используйте вариант 2 (перетаскивание архива на browser://tune) или Chrome.
  • «Компьютер не является корпоративным» — ExtensionInstallForcelist не применяется на неуправляемых ПК; это ожидаемо.
  • Windows блокирует скачанный .bat — файл скачан из интернета, поэтому система помечает его; нажмите «Подробнее» → «Выполнить в любом случае» либо снимите блокировку в свойствах файла.
  • Как откатить всё — запустите CLEAN-POLICY.bat от имени администратора и перезапустите браузер.

Внимание: файлы .reg и .bat изменяют системные политики браузеров. Применяйте их только на своих компьютерах. Приватный ключ подписи расширения хранится локально у владельца и никогда не публикуется — иначе кто-то сможет выпустить расширение с тем же ID.
