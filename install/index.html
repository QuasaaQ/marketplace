Установка расширений

Расширение ставится прямо с этого сайта: выберите свой вариант установки - от него зависят шаги, - а потом нажмите «Скачать .crx» в карточке нужного расширения ниже.

Выберите способ установки - от него зависят шаги:

Установка с правами администратора

Найдите свой браузер и идите по шагам ниже - инструкция самодостаточна, второй блок читать не нужно. Пакет политик включается в шаге 1: после него расширения ставятся в один клик прямо с сайта, а обновления приходят автоматически. Сам файл расширения от политик не зависит.

Яндекс Браузер

  1. Установите бета-версию Яндекс Браузера.
  2. Скачайте APPLY-POLICY.bat и запустите его от имени администратора: он сам запросит UAC и включит установку с нашего сайта.
  3. Полностью закройте браузер - все окна и иконку в трее - и запустите заново.
  4. Нажмите «Скачать .crx» - распаковывать не нужно. Браузер сразу предложит установку.

Chrome

  1. Скачайте APPLY-POLICY.bat и запустите его от имени администратора: он сам запросит UAC и включит установку с нашего сайта.
  2. Полностью закройте Chrome - все окна и фоновые процессы - и запустите заново.
  3. Проверьте chrome://policy: ExtensionInstallSources и ExtensionInstallAllowlist должны быть в статусе ОК.
  4. Нажмите «Скачать .crx» - распаковывать не нужно. Chrome сразу предложит установку.

В Chrome больше нет расширений старого Manifest V2: полный uBlock Origin там не поставится, для рекламы есть uBlock Origin Lite. В Яндекс Браузере Manifest V2 работает и без политик.

Другие файлы

  • Вместо APPLY-POLICY.bat можно применить install-policy.reg - тот же набор политик одним файлом реестра. Применять нужно с правами администратора и не двойным кликом: двойной клик права не запрашивает, и Windows молча откажет в записи ветки Policies. Из консоли администратора: reg import install-policy.reg.
  • install-policy-corporate.reg - политики плюс автоустановка (ExtensionSettings, force_installed) для управляемых ПК.
  • CLEAN-POLICY.bat - откат: удаляет все политики проекта, список расширений не трогает.

Установка без прав администратора

Бета-версия Яндекс Браузера - единственный вариант без прав администратора: скачанный файл перетаскивается прямо в окно браузера, политики не нужны.

  1. Установите бета-версию Яндекс Браузера.
  2. Нажмите «Скачать .crx» - распаковывать не нужно.
  3. Откройте в Браузере chrome://extensions или browser://tune.
  4. Перетащите скачанный файл в окно Браузера и подтвердите установку.
  5. Расширение появится в разделе «Из других источников».

Chrome и стандартный Яндекс Браузер расширение не поставят: политика, установщик и перетаскивание там требуют администратора. Если права появятся, вернитесь к первому варианту.

Автоустановка на парк ПК (требуются права администратора)

Политика ExtensionSettings с режимом force_installed ставит расширения сама, без действий пользователя, но применяется от имени администратора и работает только на управляемых (корпоративных) компьютерах.

Если что-то не работает

  • Нужны права администратора - Chrome и стандартный Яндекс Браузер ставят расширение только из-под учётной записи администратора: для политик, установщика и перетаскивания. Единственный способ без прав администратора - бета-версия Яндекс Браузера и перетаскивание файла .crx.
  • Политика «не задана» - почти всегда неверный формат: нужен подраздел ExtensionInstallSources с нумерованными значениями REG_SZ, а не REG_MULTI_SZ. Либо браузер не был перезапущен полностью.
  • «Сайт не доверенный» в Яндекс Браузере - встроенное ограничение на сторонние расширения в стандартной версии, политикой не снимается. Без прав администратора используйте бета-версию Яндекс Браузера и перетаскивание файла .crx; в стандартной версии поможет установка через browser://tune от имени администратора.
  • «Компьютер не является корпоративным» - автоустановка (ExtensionSettings, force_installed) не применяется на неуправляемых ПК, это ожидаемо.
  • Расширение старого Manifest V2 не ставится - в Chrome поддержку Manifest V2 удалили вместе с политикой ExtensionManifestV2Availability, поэтому там ставятся только расширения Manifest V3. Полный uBlock Origin работает в Яндекс Браузере; для Chrome есть uBlock Origin Lite. Политики на это не влияют.
  • Политика не появилась в browser://policy - файл .reg применили без прав администратора. Ветка SOFTWARE\Policies доступна только на запись администраторам (владелец - BUILTIN\Администраторы, у пользователя только чтение), и Windows в этом случае отказывает молча. Запустите APPLY-POLICY.bat и подтвердите UAC, либо примените .reg из консоли с правами администратора: reg import install-policy.reg. Политики пишутся в машинные ветки: проверить можно командой reg query "HKLM\SOFTWARE\Policies\Google\Chrome" /v ExtensionInstallSources.
  • Windows блокирует скачанный .bat - «Подробнее» → «Выполнить в любом случае».
  • Как откатить всё - запустите CLEAN-POLICY.bat от имени администратора и перезапустите браузер.

Файлы .reg и .bat изменяют системные политики браузеров - применяйте их только на своих компьютерах. Приватные ключи подписи хранятся локально и никогда не публикуются.
