Установка в один клик

Этот способ разрешает браузеру ставить расширение прямо с этого сайта, без ручного «Загрузить распакованное». Работает для Яндекс Браузера, Chrome и Chromium на ваших рабочих ПК.

Ограничение браузеров: установка расширений с произвольных сайтов запрещена с 2012 года. Разрешить её можно только политикой, которая один раз настраивается на компьютере (нужны права администратора). После этого установка — действительно в один клик. Обновления расширения будут приходить автоматически.

Шаг 1. Один раз разрешить установку с сайта

  1. Скачайте файл политики: install-policy-all.reg — в нём сразу оба правила (клик по .crx и автоустановка).
  2. Кликните по нему правой кнопкой → Слияние (или запустите от имени администратора). Подтвердите запрос UAC и добавление данных в реестр.
  3. Полностью закройте браузер (все окна) и откройте заново — политики читаются при запуске.
  4. Проверить, что политика применилась: откройте browser://policy (Chrome: chrome://policy) и найдите ExtensionInstallSources.

Шаг 2. Установить расширение

Yen → RUB для DeepSeek Версия 1.0.0 · ID: cdoacknmgmgemgkhjemnlcmebofaldnb
Установить в один клик
  1. Нажмите кнопку «Установить в один клик» выше.
  2. Браузер покажет запрос на установку — подтвердите Добавить расширение.
  3. Готово: расширение появится на странице browser://extensions и начнёт работать на platform.deepseek.com.

Вариант без кликов: автоматическая установка

Если нужно развернуть расширение сразу на нескольких ПК, удобнее форсированная установка: браузер сам скачает и поставит расширение, а затем будет обновлять его.

install-policy-forcelist.reg Автоустановка и автообновление по адресу update.xml
Скачать .reg
  1. Примените install-policy-forcelist.reg так же, как файл из шага 1.
  2. Перезапустите браузер — расширение установится само.

Технические данные

  • ID расширения: cdoacknmgmgemgkhjemnlcmebofaldnb
  • Файл расширения: yen-to-rub.crx
  • Манифест обновлений: update.xml
  • Политика разрешения источников: install-policy-sources.reg
  • Политика автоустановки: install-policy-forcelist.reg
  • Оба правила в одном файле: install-policy-all.reg
  • Ветки реестра: HKCU, HKLM (64-бит) и HKLM WOW6432Node (32-бит) для Яндекс Браузера, Chrome и Chromium

Если что-то не работает

  • Ошибка «CRX_REQUIRED_PROOF_MISSING» — политика не применилась. Проверьте browser://policy и перезапустите браузер полностью.
  • Клик по кнопке просто скачивает файл — нет политики ExtensionInstallSources или домен указан с ошибкой.
  • Политика не видна в списке — файл .reg не был применён (нужны права администратора) или браузер не перезапускался.
  • Как убрать расширение — на странице browser://extensions; для отмены политик удалите соответствующее значение в Regedit и перезапустите браузер.

Внимание: .reg изменяет системные политики браузера. Применяйте его только на своих ПК и понимайте, что делаете. Приватный ключ подписи расширения хранится только локально у владельца и никогда не публикуется — иначе кто-то сможет выпустить расширение с тем же ID.
