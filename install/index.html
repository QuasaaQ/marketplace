Установка расширений

Без прав администратора расширение ставится только в бета-версию Яндекс Браузера - перетаскиванием файла .crx. Все остальные способы (политики для Chrome, установщик и перетаскивание в стандартном Яндекс Браузере, автоустановка на парк ПК) требуют учётной записи администратора.

Яндекс Браузер Бета - без прав администратора

Бета-версия Яндекс Браузера - единственный вариант без прав администратора: скачанный файл .crx перетаскивается прямо в окно браузера, политики не нужны.

  1. Установите бета-версию Яндекс Браузера.
  2. Нажмите «Скачать .crx» у нужного расширения ниже - распаковывать не нужно.
  3. Откройте в Браузере chrome://extensions или browser://tune.
  4. Перетащите скачанный файл .crx в окно Браузера и подтвердите установку.
  5. Расширение появится в разделе «Из других источников».

Chrome - установка в один клик (требуются права администратора)

  1. Скачайте install-policy.reg и примените его с правами администратора. Проще всего запустить APPLY-POLICY.bat - он сам запросит UAC. Важно: при двойном клике по .reg повышение прав не запрашивается, и Windows молча отказывает в записи ветки Policies - файл «применится», а политики в браузере не появятся.
  2. Полностью закройте Chrome - все окна и фоновые процессы - и запустите заново.
  3. Проверьте: chrome://policy → ExtensionInstallSources и ExtensionManifestV2Availability должны быть в статусе ОК.
  4. Нажмите «Скачать .crx» у нужного расширения ниже: после политики Chrome сразу предложит установку.

Файл политик заодно включает ExtensionManifestV2Availability = 2 (Force enabled): браузер перестаёт сам отключать и удалять расширения устаревшего Manifest V2.

Яндекс Браузер Бета - установка в один клик через политику (требуются права администратора)

Бета-версия Яндекс Браузера работает как Chrome: после применения политик расширения ставятся в один клик прямо с сайта, а обновления приходят автоматически. Применение политик требует прав администратора.

  1. Скачайте install-policy.reg и примените его с правами администратора: лучше через APPLY-POLICY.bat, который сам запрашивает UAC.
  2. Полностью закройте браузер - окна и иконку в трее - и запустите заново.
  3. Нажмите «Скачать .crx» у нужного расширения ниже: Браузер сразу предложит установку.

Яндекс Браузер (стандартная версия) - установщик или перетаскивание (требуются права администратора)

Яндекс Браузер не разрешает ставить сторонние расширения с сайтов и отвечает «Невозможно добавить приложение, расширение или пользовательский скрипт с этого сайта». Работают два способа, оба требуют прав администратора.

Способ 1 - установщик

  1. Нажмите Скачать установщик у нужного расширения ниже.
  2. Запустите файл от имени администратора: он сам скачает расширение и зарегистрирует его.
  3. Полностью закройте Яндекс Браузер - окна и иконку в трее - и запустите заново.
  4. Откройте browser://extensions и один раз подтвердите расширение.

Способ 2 - перетаскивание

  1. На странице расширения нажмите Скачать .crx - распаковывать не нужно.
  2. Откройте в Браузере страницу browser://tune.
  3. Перетащите скачанный файл .crx в окно Браузера и подтвердите установку. Без прав администратора этот способ не работает.
  4. Расширение появится в разделе «Из других источников».

Автоустановка на парк ПК (требуются права администратора)

Политика ExtensionSettings с режимом force_installed ставит расширения сама, без действий пользователя, но применяется от имени администратора и работает только на управляемых (корпоративных) компьютерах.

install-policy-corporate.reg Политики Sources + Allowlist + MV2 + ExtensionSettings
Скачать .reg

Скрипты применения и отката политик во всех браузерах (запрашивают права администратора сами):

APPLY-POLICY.bat Включает установку из нашего сайта (Sources + Allowlist) и разрешает Manifest V2
Скачать .bat
CLEAN-POLICY.bat Удаляет установленные политики (откат)

Если что-то не работает

  • Нужны права администратора - Chrome и стандартный Яндекс Браузер ставят расширение только из-под учётной записи администратора: для политик, установщика и перетаскивания. Единственный способ без прав администратора - бета-версия Яндекс Браузера и перетаскивание файла .crx.
  • Политика «не задана» - почти всегда неверный формат: нужен подраздел ExtensionInstallSources с нумерованными значениями REG_SZ, а не REG_MULTI_SZ. Либо браузер не был перезапущен полностью.
  • «Сайт не доверенный» в Яндекс Браузере - встроенное ограничение на сторонние расширения в стандартной версии, политикой не снимается. Без прав администратора используйте бета-версию Яндекс Браузера и перетаскивание файла .crx; в стандартной версии поможет установка через browser://tune от имени администратора.
  • «Компьютер не является корпоративным» - автоустановка (ExtensionSettings, force_installed) не применяется на неуправляемых ПК, это ожидаемо.
  • Расширения отключаются сами - так современные сборки Chromium поступают с расширениями Manifest V2. Примените install-policy.reg или APPLY-POLICY.bat: они записывают политику ExtensionManifestV2Availability = 2 (Force enabled), и после полного перезапуска браузер их больше не отключает. На компьютере с облачным управлением (Google Admin console) то же значение нужно задать и в облачном правиле.
  • Политика не появилась в browser://policy - файл .reg применили без прав администратора. Ветка SOFTWARE\Policies доступна только на запись администраторам (владелец - BUILTIN\Администраторы, у пользователя только чтение), и Windows в этом случае отказывает молча. Запустите APPLY-POLICY.bat и подтвердите UAC, либо примените .reg из консоли с правами администратора: reg import install-policy.reg. Текущее значение можно проверить командой reg query "HKCU\SOFTWARE\Policies\YandexBrowser" /v ExtensionManifestV2Availability.
  • Windows блокирует скачанный .bat - «Подробнее» → «Выполнить в любом случае».
  • Как откатить всё - запустите CLEAN-POLICY.bat от имени администратора и перезапустите браузер.

Файлы .reg и .bat изменяют системные политики браузеров - применяйте их только на своих компьютерах. Приватные ключи подписи хранятся локально и никогда не публикуются.
