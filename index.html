Как установить расширение

Chrome и Яндекс Браузер работают одинаково — расширения ставятся из ZIP-архива.

  1. Скачайте .zip нужного расширения с этой страницы и распакуйте его в любую постоянную папку (например Документы\Extensions).
  2. Откройте страницу расширений: в Chrome — chrome://extensions, в Яндекс Браузере — browser://extensions.
  3. Включите Режим разработчика (переключатель в правом верхнем углу).
  4. Нажмите Загрузить распакованное расширение и выберите распакованную папку (ту, где лежит manifest.json).

Важно: не удаляйте распакованную папку — браузер загружает расширение из неё. При первом запуске Яндекс Браузер может показать предупреждение о расширениях из неизвестного источника — это нормально для файлов, установленных вручную.
