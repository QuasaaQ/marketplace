Как установить расширение

Без прав администратора расширение ставится только в бета-версию Яндекс Браузера - перетаскиванием файла .crx. Все остальные способы требуют учётной записи администратора.

Яндекс Браузер Бета - без прав администратора

  1. Установите бета-версию Яндекс Браузера, если её ещё нет.
  2. Скачайте файл .crx на странице нужного расширения - распаковывать не нужно.
  3. Откройте chrome://extensions или browser://tune и перетащите скачанный файл в окно браузера.
  4. Подтвердите установку: расширение появится в разделе «Из других источников».

Chrome - установка в один клик (требуются права администратора)

  1. Скачайте файл политики и примените его один раз от имени администратора (правый клик → «Слияние»).
  2. Полностью закройте Chrome - все окна и фоновые процессы - и запустите заново.
  3. Откройте страницу установки и нажмите «Скачать .crx» - после политики Chrome сразу предложит установку.
  4. Нажмите на иконку расширения и завершите его настройку.

Яндекс Браузер Бета - установка в один клик (требуются права администратора)

Бета-версия Яндекс Браузера работает как Chrome: после применения политик расширения ставятся в один клик прямо с сайта, а обновления приходят автоматически. Само применение политик требует прав администратора.

Яндекс Браузер (стандартная версия) - установщик (требуются права администратора)

  1. На странице нужного расширения нажмите Скачать установщик и запустите файл от имени администратора: он скачает расширение и зарегистрирует его.
  2. Полностью закройте Яндекс Браузер - окна и иконку в трее - и запустите заново.
  3. Откройте browser://extensions и один раз подтвердите расширение.
  4. Без установщика можно вручную, тоже от имени администратора: скачайте .crx и перетащите файл в окно browser://tune - расширение появится в разделе «Из других источников».

Коротко: без прав администратора работает только бета-версия Яндекс Браузера с перетаскиванием файла .crx. В Chrome права администратора нужны для применения политики, в стандартном Яндекс Браузере - для установщика и перетаскивания, на парке ПК - для автоустановки. Подробнее - на странице Установка.
