Установка с правами администратора

Пакет политик применяется один раз. После него расширения ставятся в один клик прямо с сайта, а обновления приходят автоматически. Политики нужны только для этого - сам файл расширения их не требует.

Сначала - Яндекс Браузер

  1. Установите бета-версию Яндекс Браузера.
  2. Скачайте APPLY-POLICY.bat и запустите его от имени администратора: он сам запросит UAC и пропишет политики для Яндекс Браузера, Chrome и Chromium.
  3. Полностью закройте браузер - все окна и иконку в трее - и запустите заново.
  4. Скачайте файл .crx - распаковывать не нужно. Браузер сразу предложит установку.

Стандартный Яндекс Браузер расширения с сайтов не ставит: там работает кнопка «Скачать установщик» от имени администратора либо перетаскивание файла .crx в browser://tune.

Затем - Chrome

  1. Скачайте APPLY-POLICY.bat и запустите его от имени администратора.
  2. Полностью закройте Chrome - все окна и фоновые процессы - и запустите заново.
  3. Проверьте chrome://policy: ExtensionInstallSources и ExtensionInstallAllowlist должны быть в статусе ОК.
  4. Скачайте файл .crx - распаковывать не нужно. Chrome сразу предложит установку.

В Chrome больше нет расширений старого Manifest V2: полный uBlock Origin там не поставится, для рекламы есть uBlock Origin Lite. В Яндекс Браузере Manifest V2 работает и без политик.

Другие файлы

  • install-policy.reg - то же самое одним файлом реестра; применять нужно с правами администратора, потому что двойной клик права не запрашивает.
  • install-policy-corporate.reg - плюс автоустановка (ExtensionSettings) для управляемых ПК.
  • CLEAN-POLICY.bat - откат: удаляет все политики проекта.

Установка без прав администратора

Бета-версия Яндекс Браузера - единственный вариант без прав администратора: скачанный файл перетаскивается прямо в окно браузера, политики не нужны.

  1. Установите бета-версию Яндекс Браузера.
  2. Скачайте файл .crx - распаковывать не нужно.
  3. Откройте в Браузере chrome://extensions или browser://tune.
  4. Перетащите скачанный файл в окно Браузера и подтвердите установку.
  5. Расширение появится в разделе «Из других источников».

Chrome и стандартный Яндекс Браузер расширение не поставят: политика, установщик и перетаскивание там требуют администратора. Если права появятся, вернитесь к первому варианту.
